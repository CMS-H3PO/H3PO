# Commands used for producing Xbb-tag efficiency JSON files

Initialize environment variables
```
export SUFFIX="$(git rev-parse --short HEAD)"
export CONDOR_OUTPUT=~/HHH
```
In this particular case `SUFFIX` was corresponding to `a50db1b`. Next, submit Condor jobs
```
python condor_selection.py -y 2016APV -o ${CONDOR_OUTPUT}/condor_jobs_XbbEffMaps_2016APV_${SUFFIX} -m 8000 -t PFHT1050 AK8PFJet500 PFJet500 -d XToYHTo6B --extra_histos --date_only --requirements 'machine != "lorientree05.hep.zef.irb.hr"'
```
```
python condor_selection.py -y 2016 -o ${CONDOR_OUTPUT}/condor_jobs_XbbEffMaps_2016_${SUFFIX} -m 8000 -t PFHT1050 AK8PFJet500 PFJet500 -d XToYHTo6B --extra_histos --date_only --requirements 'machine != "lorientree05.hep.zef.irb.hr"'
```
```
python condor_selection.py -y 2017 -o ${CONDOR_OUTPUT}/condor_jobs_XbbEffMaps_2017_${SUFFIX} -m 8000 -t PFHT1050 AK8PFJet500 PFJet500 -d XToYHTo6B --extra_histos --date_only --requirements 'machine != "lorientree05.hep.zef.irb.hr"'
```
```
python condor_selection.py -y 2018 -o ${CONDOR_OUTPUT}/condor_jobs_XbbEffMaps_2018_${SUFFIX} -m 8000 -t PFHT1050 AK8PFJet500 PFJet500 -d XToYHTo6B --extra_histos --date_only --requirements 'machine != "lorientree05.hep.zef.irb.hr"'
```
Once all jobs complete successfully, output histograms need to be combined and numerator and denominator historgrams produced for each year
```
export TIMESTAMP=20260821
export YEAR=2016APV
```
```
python combine_histograms.py -y ${YEAR} -i ${CONDOR_OUTPUT}/condor_jobs_XbbEffMaps_${YEAR}_${SUFFIX}_${TIMESTAMP} -p XToYHTo6B --skip_norm
python ../tools/plotRatio.py -i ${CONDOR_OUTPUT}/condor_jobs_XbbEffMaps_${YEAR}_${SUFFIX}_${TIMESTAMP}/fit/XToYHTo6B_Histograms.root -n fatjet_eta_pt_xbbTag_SR_*boosted_nominal -d fatjet_eta_pt_all_SR_*boosted_nominal -o ak8_eta_pt_xbbTagEff_${YEAR}_SR_XToYHTo6B --binomial --batch --save_histo
python ../tools/plotRatio.py -i ${CONDOR_OUTPUT}/condor_jobs_XbbEffMaps_${YEAR}_${SUFFIX}_${TIMESTAMP}/fit/XToYHTo6B_Histograms.root -n fatjet_eta_pt_xbbTag_VR_*boosted_nominal -d fatjet_eta_pt_all_VR_*boosted_nominal -o ak8_eta_pt_xbbTagEff_${YEAR}_VR_XToYHTo6B --binomial --batch --save_histo
```
